# Stock Portfolio Tracker – CodeAlpha Internship

## Project Overview

This project is a simple Stock Portfolio Tracker developed in Python as part of my CodeAlpha internship.

The program allows users to select stocks, enter the quantity they own, calculate the investment value, view their total portfolio value, and save the portfolio information to a text file.

## Features

- Predefined stock prices using a Python dictionary
- Multiple stock selection
- Quantity input
- Quantity validation
- Invalid stock detection
- Individual investment calculation
- Total portfolio investment calculation
- Portfolio summary
- Save portfolio information to a text file

## Technologies Used

- Python
- Dictionary
- Lists
- Strings
- Loops
- Conditional statements
- Functions
- File handling
- Exception handling
- User input

## How It Works

1. The program displays available stocks and their predefined prices.
2. The user enters a stock symbol.
3. The user enters the quantity.
4. The program calculates the investment value.
5. The user can add multiple stocks.
6. The user enters `done` when finished.
7. The program displays the portfolio summary and total investment.
8. The portfolio is saved to `portfolio.txt`.

## How to Run

Run `stock_portfolio_tracker.py` using a Python environment such as Pydroid 3.
